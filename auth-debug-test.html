🧪 Debug Commands (Run in Browser Console)

1. Check Firebase Auth State

// Check current Firebase auth state
import { auth } from './src/lib/firebase.js';
console.log('🔍 Firebase Auth Object:', auth);
console.log('🔍 Current User:', auth.currentUser);
console.log('🔍 Auth Domain:', auth.config?.authDomain);

// Listen for auth changes
auth.onAuthStateChanged(user => {
    console.log('🔄 Auth state changed:', user ? `${user.email} (${user.uid})` : 'No user');
});

2. Check Auth Singleton

// Check auth singleton state
import authSingleton from './src/lib/authSingleton.js';
console.log('🔍 Auth Singleton Current User:', authSingleton.getCurrentUser());
console.log('🔍 Auth Singleton Initialized:', authSingleton.initialized);
console.log('🔍 Auth Singleton Listeners:', authSingleton.listeners.size);

// Initialize if needed
if (!authSingleton.initialized) {
    authSingleton.initialize().then(user => {
        console.log('✅ Auth singleton initialized:', user ? user.uid : 'no user');
    });
}

🔍 Expected Results

✅ If Authentication is Working:

  • Firebase Auth: auth.currentUser should be an object with user data
  • Auth Singleton: getCurrentUser() should return user object
  • Local Storage: Should contain Firebase auth tokens
  • Demo Mode: Should be undefined or "false"

❌ If Authentication is NOT Working:

  • Firebase Auth: auth.currentUser will be null
  • Auth Singleton: getCurrentUser() will return null
  • Local Storage: Missing or invalid Firebase auth tokens
  • Console Errors: Look for CORS, configuration, or network errors

🛠️ Troubleshooting Steps

Step 1: Clear Browser Data

  1. Open Chrome DevTools (F12)
  2. Go to Application → Storage
  3. Click "Clear site data"
  4. Refresh the page
  5. Try signing in again

Step 2: Check Firebase Console

  1. Go to Firebase Auth Users
  2. Check if your user account exists
  3. Verify the auth domain is set correctly

Step 3: Test in Incognito Mode

  1. Open Chrome in incognito mode
  2. Go to the WIZ Magic Platform
  3. Try signing in fresh
  4. Check if the issue persists

Step 4: Check Network Tab

  1. Open DevTools → Network tab
  2. Try signing in
  3. Look for failed requests (red entries)
  4. Check for CORS or 403 errors
