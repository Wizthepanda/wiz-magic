🎯 XP System Production Test

This page tests the new production XP system deployed to Firebase.

Test Instructions:

  1. Go to https://wiz-magic-platform.web.app
  2. Sign in to your account
  3. Open browser console (F12)
  4. Run the test commands below

🧪 Test Commands (Run in Browser Console)

1. Test Video Completion XP

// Import the client function
const { awardVideoCompletion } = await import('./src/lib/xp/awardXpClient.js');

// Award XP for a test video
const result = await awardVideoCompletion('test_video_' + Date.now(), 10, 45);
console.log('XP Award Result:', result);

2. Test Share XP

// Import share function  
const { awardShare } = await import('./src/lib/xp/awardXpClient.js');

// Award share XP
const shareResult = await awardShare('shared_video_' + Date.now());
console.log('Share XP Result:', shareResult);

3. Check Auth Singleton

// Check auth state
const authSingleton = await import('./src/lib/authSingleton.js').then(m => m.default);
console.log('Current user:', authSingleton.getCurrentUser());
console.log('Is authenticated:', authSingleton.isAuthenticated());

4. Listen to XP Events

// Listen for XP update events
window.addEventListener('xpUpdated', (event) => {
    console.log('🎯 XP Updated Event:', event.detail);
});

window.addEventListener('levelUp', (event) => {
    console.log('🆙 Level Up Event:', event.detail);
});

5. Check Offline Queue

// Check offline queue status
const { getOfflineQueueStatus } = await import('./src/lib/xp/awardXpClient.js');
console.log('Offline Queue:', getOfflineQueueStatus());

🚨 Troubleshooting

If XP Not Awarded:

  • Check if user is signed in
  • Check browser console for errors
  • Verify Firestore security rules are deployed
  • Check daily XP cap (360 XP max)

If Import Errors Occur:

  • Files might be bundled differently in production
  • Try accessing functions through window object
  • Check Network tab for 404 errors
  • Verify build includes new XP files

📊 Production Health Checks

Firebase Console Verification:

  1. Check Firestore - Verify user documents have currentXP, dailyXpEarned fields
  2. Check Rules - Ensure new security rules are active
  3. Check Hosting - Verify latest deployment is live

🎉 Success Criteria

The XP system is working correctly if:

  • ✅ XP awards complete without errors
  • ✅ UI updates immediately with XP feedback
  • ✅ Firestore documents are created/updated correctly
  • ✅ Daily XP caps are enforced
  • ✅ Level-ups trigger at proper thresholds
  • ✅ No duplicate XP awards for same video
  • ✅ Offline queue processes when back online
